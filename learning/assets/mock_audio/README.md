# 原创模考听力样例

这些 MP3 的文本来自 `learning/mock_bank.py`，用 eSpeak NG 离线合成、ffmpeg 编码。文本与音频为本项目原创练习内容，不是官方考试录音或真题，不含真人声音克隆。

每个考试两组样例，语速不同；音色为合成示例，未作真实考场音质或难度校准。只在用户点击播放时使用，不录音、不调用付费 TTS API。

生成脚本为 `tools/generate_mock_audio.py`。语音引擎仅用于生成这些文件，不随应用部署或分发；eSpeak NG/ffmpeg 的运行库无需加入 Flask 依赖。应用在已登录、已拥有对应模考的音频路由提供这些文件，支持浏览器 Range 请求。
