# AI 伴学精简

总览优先展示专项练习、模拟考试、错题复习。考试卡片仅显示名称，移除重复介绍，保留作答限制、AI 消息消耗、同步状态及非官方评分等必要信息。学习页样式独立于主聊天，使用系统字体、单色卡片和至少 44px 的操作区域，并考虑 iPhone 安全区。

学习菜单提供自动、浅色、深色选项，复用原有 `chat-theme.js` 与 `fishyeah-chat-theme` 偏好。没有修改共用主题脚本。

## 听力下线与数据兼容

- 专项下拉框、模考选择、学习任务均不再提供听力，删除前端音频播放器与转写展示代码。
- 新诊断使用 `entry-v2` 三组五题，移除听力题。保留 `entry-v1` 注册表，支持旧结果读取、幂等重放及旧错题解析。旧结果不重新计算，趋势仍沿用同版本比较。
- 历史练习和模考报告保留可读；旧听力错题仅保留查看，不再提供练习表单。已保存计划不重写，其听力任务不再显示。
- 旧进行中的听力模考不会重新展示题目。用户可明确确认结束，提交已有服务器答案，保留报告后继续其他模考；不会自动提交或清除学习数据。
- 保留后端旧听力接口、题库与音频资产作为兼容层；本次不更改数据库结构、AI 模型、计费规则、登录、会员或支付。

## 验证

浏览器集成覆盖 Chromium 与 WebKit，390 / 375px 手机及 1440px 桌面，浅色与深色、手动主题与自动主题、键盘焦点、横向溢出、草稿恢复、离线同步、旧听力模考结束及报告保存。后端增加旧诊断重放、五题轮换及旧听力弱项不生成新任务的回归检查。

本次仅提交 PR，暂不合并或部署 Render。

验证结果：`python -m pytest -q` 全量 242 项通过（含 Chromium / WebKit 浏览器集成），`node tests/test_stream.js` 4 项通过，学习页与主题脚本的 `node --check` 及 `git diff --check` 通过。测试使用临时 PostgreSQL 和模拟 AI，不连接生产学习数据。静态 HTML 文本（去除标签与空白）从 1303 字符减至 611 字符，约减少 53%；不含动态学习数据。
