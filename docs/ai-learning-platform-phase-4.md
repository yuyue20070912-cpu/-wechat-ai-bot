# 第四阶段：时区、轮换筛查与计时分项模考

## 先修复的两个问题

### 学习日时区

新增账户级 `learning_preferences`，默认 `Asia/Shanghai`，可在学习中心填写其他 IANA 时区（例如 `America/New_York`）。服务器同时验证 Python tzdata 和 PostgreSQL 支持，不接受客户端自定义偏移或非法时区。

今日计划按数据库当前时间在用户时区的日期生成/恢复；数据中心的活动日、28 天格子也使用用户时区。计划仍按“用户 + 考试 + 日期”唯一，不因切换时区覆盖同日期已完成的任务。旧计划保留原时区快照；用户切回某日期时恢复原任务，而不是重建。跨日期切换会显示相应日期已有或新建的计划。

时区设置有版本校验，旧并发更新不会覆盖新设置。目标、自评或筛查更新仍在下一份计划中应用。**消息与 AI 每日调用预算仍按 UTC 重置**，切时区不能刷新额度。计时模考保存的是绝对截止时间，与时区设置无关。

### 六题入门筛查题组轮换

每个考试有 A/B/C 三组不同的原创六题，共 54 道；不是只把旧题改顺序。第一次使用原 A 组，之后 B、C、A 循环。升级用户按已有该考试记录数量确定起点。

题组推进随筛查结果在同一事务提交，使用用户/考试范围行锁；同一请求重放不推进题组，并发不同请求不能重复消耗同一轮。提交过期题组返回 409，已完成请求仍可幂等恢复。原 `entry-v1` 题组与历史结果保持可读。

页面明确标注“六题轮换入门筛查，不能代表完整英语水平”；返回 `scope=entry_screening`、`level_is_proficiency=false`。正确率与“基础起步”等描述只观察该题组，不作 CEFR、完整水平或官方成绩判断。不同题组不直接计算正确率增减；题组有限，重复有记忆效应。

## 模考范围

所有内容都是 **原创分项短卷**，不是完整考试、官方真题或难度校准后的题库。

| 考试 | 分项 | 每卷题量 / 时间 |
| --- | --- | --- |
| IELTS | 听力 | 3 道客观题 / 5 分钟 |
| IELTS | 阅读 | 4 道客观题 / 10 分钟 |
| IELTS | 写作 | 1 道文字论述 / 20 分钟 |
| IELTS | 口语文字模拟 | 1 道文字表达 / 4 分钟，不录音、不评发音 |
| CET-4 / CET-6 | 听力、阅读 | 各 3 / 4 道客观题，5 / 10 分钟 |
| CET-4 / CET-6 | 写作、翻译 | 各 1 道主观题，20 / 10 分钟 |
| CET-4 / CET-6 | 词汇拓展 | 4 道客观题 / 5 分钟，非独立官方计分分项 |

每个分项两组短卷，共 28 份模板。每场开始时保存完整服务器题目快照，后续题库代码变化不会更改该场答案或判分标准。

### 听力音频

六个预先生成的原创英语 MP3，使用 eSpeak NG 离线合成、ffmpeg 编码，合计约 1 MB。语音引擎不随 Flask 部署，不在请求时调用任何 TTS API。内容和合成音色为练习样例，不是官方录音，也没有真人声音克隆。

用户手动播放，使用原生 `<audio>`，不自动播放、不录音。音频由需登录且核验模考归属的接口提供，支持 HEAD/Range 请求。听力转写只在交卷/到时报告中提供；进行中不返回正确选项或解析。音频可以回放，不能据此声称为严格真实考场模拟。

生成方式见 `tools/generate_mock_audio.py` 与 `learning/assets/mock_audio/README.md`。运行 Flask 不需要额外语音软件。

## 计时与答案恢复

- 开始时间与固定截止时间来自数据库。客户端不能设置时长、暂停、延长或伪造交卷时间；刷新、断线与切时区都不重置计时。
- 同一用户最多一场 active 模考，数据库部分唯一索引强制执行。开始 UUID 重试恢复同场，换模板但复用编号返回 409。
- 浏览器使用服务器剩余秒数及单调时钟显示倒计时。到时禁用输入并请求服务器报告；即使页面关闭，之后任何恢复/保存/新开模考也会检查原绝对截止时间。
- 结算采用访问时检查，不依赖后台定时工作进程。写请求**取得行锁后**用 `clock_timestamp()` 检查截止时间，避免等待锁的事务用旧 NOW 时间越过截止。
- 每次暂停输入 500ms 自动同步，连续写作时另有 5 秒周期同步。保存/交卷均包含请求 UUID、期望版本和答案补丁。每用户最多 120 次写请求/分钟。
- 重复 UUID 相同内容返回回执；内容不同或旧版本冲突返回 409。保存回执仅存规范化答案补丁的 SHA-256，不重复保存每次作文全文。当前答案仍保存在模考记录中。
- 离线草稿和未确认请求暂存 `sessionStorage`，按已登录账户 HMAC 范围及模考 ID 隔离。恢复前先经服务器登录与所有权验证；不会把上一账号草稿作为另一账号的答案恢复。
- 网络恢复后使用同一请求编号同步，已成功但丢失响应的保存不会写两遍。多标签页冲突保留本页草稿，并要求用户明确选择恢复服务器状态，不静默覆盖。
- 交卷后不可修改。到时只统计此前服务器已同步答案，迟到的新答案不会计分。关闭标签页、清理浏览器或超过截止时间，不能保证未同步草稿进入报告；页面开始前和进行中均明示这一点。

## 判分、解析与历史

客观题按快照答案自动判分，未答算错，报告显示正确题数、总题数、正确率、原答案、参考答案与原创解析；听力包含转写。

主观题默认未评分，不用 0 分伪装成评估结果。未来获准启用时，用户可主动请求一次 AI 参考评分：

```text
LEARNING_AI_ENABLED=1
LEARNING_MOCK_AI_ENABLED=1
```

两者默认关闭。AI 请求复用原付费反馈路径：一条现有消息/会员额度，原用户/全站每日预算、每分钟限流、每用户最多一个 pending、输入/输出上限、超时、零自动重试与 `store=False` 全部保留。每场/每道主观题使用固定服务器请求 UUID，重复访问返回已保存反馈；失败按原账本退消息额度但不退调用预算，不自动重试。

AI 只给 0–100 **文字学习参考分**，不换算 IELTS band、CET 710 分或官方总分。口语文字模拟不评发音、语速或真实流利度。AI 分数与客观正确率分别显示，不合成官方成绩。

历史每页 20 场；报告仅对比相同考试/分项/题组/版本最近 10 场，独立展示客观正确率和已产生的主观 AI 参考均分。未请求或失败的 AI 评分不填成 0。不同题组不直接比较难度或能力，重复同题组有记忆效应。

模考 AI 记录不混入日常 AI 技能均分、筛查正确率或自动错题导入。模考错题解析位于对应模考报告中。
完成模考会计入该用户时区的学习活动日，但模考分数仍在独立报告中观察。

## API 与权限

沿用原 Session、CSRF 和私有 `no-store` 响应。客户端不能指定用户、题目快照、答案键、模型或费用上限。

| 方法 | 路径（以 `/api/learning/` 开始） | 用途 |
| --- | --- | --- |
| GET/PUT | `preferences` | 读取/修改 IANA 时区及版本 |
| GET | `mock-catalog/<exam>` | 分项短卷目录，无答案键 |
| GET/POST | `mocks` | 分页历史/当前模考；开始模考 |
| GET | `mocks/<id>` | 恢复答案、计时或报告 |
| PUT | `mocks/<id>/answers` | 幂等保存答案补丁 |
| POST | `mocks/<id>/submit` | 截止前保存并交卷，或恢复已结束报告 |
| GET/HEAD | `mocks/<id>/audio` | 本人模考音频，支持 Range |
| POST | `mocks/<id>/ai/<question>` | 主动申请一次可选参考评分 |

所有记录、音频与评分都核验 Session 所有权。未知/其他用户记录返回 404，未登录 401，CSRF 403，格式错误 400，过大请求 413，版本/状态冲突 409，限流 429，服务故障返回通用错误。不在日志记录作文、模型全文或凭证。

## 迁移与回退

新增 `004_learning_mock_exams.sql` 只建独立偏好、筛查轮换、模考与保存回执表/索引，无旧表 ALTER、无自动回填。显式迁移仍用单事务、互斥锁和短超时，不在 HTTP 请求中建表。

必须先迁移再发布新代码；回退应用时保留新表和原学习任务。旧日期计划保持原快照，旧筛查记录与旧练习可读。自动测试验证第四阶段 SQL 失败时撤回新表且保留原任务；修复后重复迁移不丢状态。正式执行仍须遵循 [安全方案](learning-rollout-safety.md)，本次未操作正式数据库。
